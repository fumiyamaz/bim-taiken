## アイデア集

### プロトタイプに実装済み
- **CAD vs BIM**: 線だけの図面には答えられない質問（窓の数、南面窓の面積）に BIM モデルなら答えられる
- **コードで建物をつくる**: 壁・床・屋根・柱・梁・窓・扉・ダクト・開口の 9 種の部材クラス
- **数量拾い・5D**: 種別/材料ごとの体積・重量・概算費用、コンクリート/型枠/鉄筋の概算
- **パラメトリック**: 設計案 4 つの比較表、スライダー（ipywidgets）で即時更新
- **干渉チェック**: 直方体同士の重なりを検出し、3D で赤く表示。開口（スリーブ）で解消できる
- **4D**: 階ごと・種別ごとの工程を自動割当、ガントチャート + 建設アニメーション
- **IFC**: IFC4 形式で書き出し（空間構造・Pset・材料・開口/充填関係つき）、IfcOpenShell で読み戻し

### 発展アイデア（次のステップ候補）
1. **実在の IFC を解剖する**: buildingSMART や IfcOpenShell の公開サンプル IFC を読み込み、部材数・階層・属性を集計する。「BIM はデータベース」をより実感できる
2. **設計変更タイムアタック**: 「全部の壁を 10cm 厚く」を、2D CAD 風の手作業（表を手で直す）と BIM（パラメータ変更）で比較し、所要時間と転記ミスを体感する
3. **グループ演習（建築・構造・設備）**: 3 班が同じ建物に別々の部材を追加し、統合して干渉チェック。Colab のノートブック共有で擬似的な「協働設計」ができる
4. **Sカーブ・出来高**: 4D の工程に費用を掛けて、累積コスト曲線を描く（5D の深掘り）
5. **環境・法規チェック**: 体積 × CO2 原単位で環境負荷、窓面積比で採光、扉からの避難距離など「情報の活用」の例を増やす
6. **LOD（詳細度）の体験**: 同じ壁を LOD100→300→400 と情報を増やしながら表現し、段階ごとの用途を説明する
7. **自然言語 × BIM**: 「南に窓を追加して」という文を LLM にコード化させて実行する。生成 AI と BIM の接点を見せられる
8. **点群→BIM / 維持管理**: 竣工後に「メーカー・設置日・点検履歴」属性を使い、FM（維持管理）での活用を演習にする

## 教材の前提・制約（授業で補足すると良いこと）
- 単価・原単位・工程日数はすべて **教材用の仮の数値** です
- 部材はすべて軸に平行な直方体に簡略化しています（斜め壁・曲面・勾配屋根は扱わない）
- 干渉チェックは直方体の AABB 判定です。本物のツールは正確な形状同士で判定します
- 書き出す IFC は最小限の構成です（ビューアで開けて属性が読める程度。認証済み IFC ではありません）

## ライブラリを改造したいとき
`minibim.py` を編集した後、次のコマンドで `bim_taiken.ipynb` を作り直せます（nbformat が必要）。

```bash
uv run --with nbformat,plotly,pandas,numpy python make_notebook.py bim_taiken.ipynb
```

新しい材料は `MATERIALS` 辞書に追加、新しい部材は `Element` を継承すると `show()`、`to_dataframe()`、`check_clashes()`、`to_ifc()` がそのまま使えます。
